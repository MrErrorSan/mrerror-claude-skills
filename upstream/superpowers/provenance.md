# Provenance: Anvil 1.0 against Superpowers 7.0.2

- **Baseline:** obra/superpowers v7.0.2 (`22f0b463`), synced 2026-11-18. See [baseline.json](baseline.json).
- **Status column:** from `tools/provenance.py` (`classify`). Line endings are normalised and the source-line comment is ignored. **Verbatim** means identical. **Lightly edited** means a word-level similarity of 0.85 or more. **Adapted** means below 0.85. When a file has several sources, the status is given for each one.
- **Kept / Changed columns:** from the implementer lane reports (T1–T12).
- **Diffs:** [provenance/diffs/](provenance/diffs/) holds one diff per mapped file, from the Superpowers source to the Anvil file. Verbatim files have no diff.
- **Map:** [source-map.json](source-map.json) is generated from the source-line comments plus [manual-sources.json](manual-sources.json). Superpowers paths are relative to the Superpowers repo root.

Where a lane called a file "lightly edited" and the tool says "adapted", the tool's word stands, and the lane's note is kept in the Changed cell. This applies to `root-cause-tracing.md`, `defense-in-depth.md` and `builder-check.md`.
